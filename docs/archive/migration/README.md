# Migration Archive

This directory preserves the completed TM-0 through TM-10 Theme Manager migration programme as historical engineering provenance.

These records explain the audits, architectural decisions, staged implementation and final legacy-retirement work used to establish the current Theme Manager. They are retained for traceability and maintenance archaeology.

They are **not current usage documentation, public API authority or required reading for consumers**.

For current documentation, start with the repository [README](../../README.md), then use the [Public Contract](../../docs/contracts.md), [Composition Contract](../../docs/composition-contract.md), [Semantic Presentation Consumer Contract](../../docs/semantic-presentation-consumer-contract.md), and [Semantic Presentation Guide](../../docs/semantic-presentation-guide.md).
