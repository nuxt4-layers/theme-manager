# Theme Editor

The editor at `/theme-manager/:id` (`/theme-manager/new` creates a Theme) edits one
Theme Definition. It edits a draft: nothing is stored until **Save**, and the rest of
the application keeps the active Theme unless *Apply to the whole app while editing*
is switched on.

## Locked files

`theme-default.css`, `theme-api.css` and `tailwind-config.css` are final and locked by
hash (`tests/presentation-lock.test.ts`). The editor never changes them: it writes the
Theme's `--ui-*` values at runtime, which reach components through the `--api-*`
mappings. The preview re-declares those mappings on `[data-theme-scope]`
(`theme-scope.css`, generated by `scripts/generate-theme-api.mjs`).

## Preview

The preview at the top renders the draft in light and dark, side by side or one at a
time, inside a scoped element. A draft that fails validation cannot be saved; the
preview keeps showing the last valid version and the reason is announced. Every tab
also previews its own tokens in both modes.

## Tabs

| Tab | Edits | Controls |
| --- | --- | --- |
| Colours | `modes.<mode>.<channel>-<role>.<state>` | Role and state matrix, colour pickers, contrast badges for every Fill/Pen/Edge pairing. A preview component's *colours* link opens its role. |
| Typography | `typography.*` | Families, sizes with their line heights, roles (a role follows a size), weights, letter spacing, line heights, code font features. |
| Spacing | `spacing`, `responsive.containers` | Length fields (px, rem, em; changing unit keeps the size). |
| Radii | `radii` | Sizes, and roles that follow a size. |
| Borders | `borders.*` | Border widths, focus ring width and offset, inset ring width. |
| Shadows | `effects.shadow`, `insetShadow`, `dropShadow`, `textShadow` | Layer editor; colours follow the role's shadow colour. |
| Effects | `effects.blur`, `perspective`, `tilt`, `aspect` | Lengths, degrees, width / height. |
| Motion | `motion.*` | Easing curve points, durations in ms, each animation's duration and easing. Specimens move only while *Play motion* is pressed. |
| Responsive | — | Read-only: breakpoints are compiled into media queries, so a Theme cannot change them. |
| Assets | — | Asset bindings (through Raw JSON until an asset provider is composed). |
| Raw | The whole definition | JSON; an edit applies once it parses and validates. |

A value a field cannot read (a `calc()`, a keyword) stays a plain text field, so the
editor never rewrites a value it does not understand. Keyframes, breakpoints and the
base spacing unit are build-time and not editable.

## Leaving and deleting

- Leaving the editor with unsaved changes (Cancel, a link, the back button) asks first
  in a dialog; *Keep editing* is the default. Closing or reloading the tab shows the
  browser's own prompt. Unsaved means the draft differs from the loaded Theme, or the
  Raw tab holds JSON that does not parse yet.
- **Delete Theme** asks in the same dialog; *Keep Theme* is the default. System Themes
  cannot be deleted.

## Accessibility

- Tabs follow the ARIA tabs pattern: one tab stop, Left and Right arrows, Home and End.
- The dialog is a native modal `<dialog>`: the page behind it is inert, focus stays
  inside, Escape cancels and focus returns to the control that opened it.
- Every field has a visible or programmatic label naming the token it edits.
- States come from platform semantics (`aria-pressed`, `aria-selected`, `:disabled`,
  `:focus-visible`); transitions never animate the focus outline.
- Specimens style themselves inline (utilities are `!important` in this layer), and
  motion specimens never move on their own.
